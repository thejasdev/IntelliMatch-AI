## Directory Purposes

**`src/components/`:**
- Purpose: Reusable UI components, modals, layout headers, and persistent visual effects.
- Contains: React functional components with Tailwind styling and SVG markup.
- Key files: `src/components/Header.jsx`, `src/components/AmbientWaveBackground.jsx`, `src/components/PdfPreviewModal.jsx`.

**`src/pages/`:**
- Purpose: Full-page view components corresponding to platform routes.
- Contains: Route-level React views handling domain filtering, user inputs, and local state.
- Key files: `src/pages/HomePage.jsx`, `src/pages/AnalyzerPage.jsx`, `src/pages/RoadmapsPage.jsx`.

**`data/`:**
- Purpose: Master knowledge base for engineering domains, competencies, projects, and roadmaps.
- Contains: ESM JavaScript arrays, configuration objects, and lookup helper functions.
- Key files: `data/jobRoles.js`, `data/roadmaps.js`, `data/projects.js`.

**`public/assets/`:**
- Purpose: Static assets directly reachable via root URL paths without Vite bundling.
- Contains: Domain SVG illustrations (`public/assets/domains/*.svg`) and PDF templates (`public/assets/resume-templates/*.pdf`).

**`.planning/`:**
- Purpose: GSD system state, project roadmaps, and codebase reference documentation.
- Contains: Markdown specifications in `.planning/codebase/`.

## Key File Locations

**Entry Points:**
- `index.html`: Browser entry document mounting the DOM root container.
- `src/main.jsx`: React entry point rendering `<BrowserRouter>` and `<App />`.
- `src/App.jsx`: Main routing table, global modal controllers, and layout scaffold.

**Configuration:**
- `package.json`: NPM package metadata, dependencies, and build scripts.
- `vite.config.js`: Vite server and build pipeline settings.
- `tailwind.config.js`: Tailwind theme tokens (colors, fonts, box shadows).
- `postcss.config.js`: CSS PostCSS pipeline plugins.

**Core Logic:**
- `data/jobRoles.js`: Core domain taxonomy, skills matrices, and role retrieval helper functions.
- `src/pages/AnalyzerPage.jsx`: ATS resume parsing simulation, skill matching heuristic, and score evaluation.
- `src/components/AmbientWaveBackground.jsx`: Multi-layer CSS keyframe-animated wave mesh and constellation orbs.

**Testing:**
- Currently not configured. No test root directory (`tests/` or `__tests__/`) exists.

## Naming Conventions

**Files:**
- React Components & Pages: PascalCase with `.jsx` extension (e.g., `Header.jsx`, `HomePage.jsx`, `PdfPreviewModal.jsx`).
- Data & Helpers: camelCase with `.js` extension (e.g., `jobRoles.js`, `matchingDemo.js`).
- Stylesheets: kebab-case or standard naming with `.css` extension (e.g., `index.css`).
- Static Domain SVGs: kebab-case with `.svg` extension matching domain IDs (e.g., `software-dev.svg`, `cloud-devops.svg`).

**Directories:**
- Source subdirectories: lowercase singular or plural (e.g., `src/components/`, `src/pages/`, `data/`, `public/assets/`).

## Where to Add New Code

**New Feature View / Route:**
- Primary code: Create new page component in `src/pages/NewFeaturePage.jsx`.
- Route registration: Register `<Route path="/new-feature" element={<NewFeaturePage />} />` in `src/App.jsx`.
- Navigation link: Add navigation link entry to `navLinks` array in `src/components/Header.jsx` and `src/components/Footer.jsx`.

**New Reusable Component:**
- Implementation: Add to `src/components/NewComponent.jsx`.
- Use existing Tailwind design tokens (`im-card`, `bg-brand-surface`, `text-brand-slate`, `border-brand-border`).

**New Domain or Skill Taxonomy:**
- Implementation: Add domain descriptor to `ENGINEERING_DOMAINS` in `data/jobRoles.js`.
- Add learning milestones to `DOMAIN_ROADMAPS` in `data/roadmaps.js`.
- Add relevant portfolio blueprints to `data/projects.js`.
- Place corresponding domain vector SVG in `public/assets/domains/<domain-id>.svg`.

**Shared Utility Helpers:**
- Helpers: Create `src/utils/` directory (e.g., `src/utils/formatters.js` or `src/utils/scoring.js`) for reusable pure functions.

## Special Directories

**`dist/`:**
- Purpose: Compiled production bundle output generated by Vite Rollup bundler.
- Generated: Yes (via `npm run build`).
- Committed: Tracked in repository for quick preview verification, but ignored in standard deployment targets.

**`_backup_pre_react/` and Legacy Root Files (`pages/`, `css/`, `js/`):**
- Purpose: Historical static HTML/JS/CSS implementation prior to React migration.
- Generated: No.
- Committed: Yes (historical artifacts; non-active in current Vite React runtime).
