# IntelliMatch brand assets

These assets were prepared from the logo images supplied in this conversation.

## Recommended use
- `intellimatch-logo-horizontal.svg`: scalable horizontal logo lockup with a traced vector symbol and text-based wordmark/tagline.
- `intellimatch-logo-horizontal.png`: transparent PNG lockup preserving the typography from the supplied image (upscaled from the source).
- `intellimatch-mark.svg`: gradient vector symbol.
- `intellimatch-mark-mono.svg`: solid black vector symbol.
- `intellimatch-mark-gradient.png`: transparent PNG of the gradient symbol.
- `intellimatch-mark-black.png`: transparent PNG of the black symbol.
- `intellimatch-wordmark-tagline.png`: transparent PNG with the supplied typography and tagline.
- `favicon.svg`: black symbol-only favicon, as requested.
- `favicon-gradient.svg`: gradient symbol-only alternative for the browser tab.
- `favicon-mono.svg`: extra monochrome alias.
- `intellimatch-logo-horizontal-vector-preview.jpg`: white-background preview of the SVG lockup.

## Recommended website usage
For the responsive website header, use the symbol and render `IntelliMatch` plus `Career Discovery & Readiness` as HTML text beside it. That keeps text accessible and responsive. Use the horizontal logo image for static brand placements, such as a README or presentation.

Suggested favicon tag:
<link rel="icon" type="image/svg+xml" href="assets/branding/favicon.svg">

If you prefer the gradient favicon, use `favicon-gradient.svg` instead.

## Notes
- The vector symbol was traced from the supplied black symbol image. Inspect at small sizes before production use.
- The PNGs are upscaled raster assets; upscaling improves display size but cannot recover details absent from the source image.
- The horizontal SVG uses live text and may render differently depending on available fonts. The PNG preserves the supplied typography more closely.
- The horizontal transparent PNG comes from a JPEG source; inspect the edges and background transparency against both light and dark backgrounds before production.
- No trademark search or legal clearance was performed.
